# 💳 AI Creditworthiness Prediction System

An AI-powered fintech application that predicts customer creditworthiness using Machine Learning.

## 🚀 Features

- Credit Risk Prediction
- Interactive Streamlit Dashboard
- Machine Learning Model
- Approval Probability Gauge
- Customer Financial Analysis
- Modern Fintech UI

## 🛠 Technologies Used

- Python
- Scikit-learn
- Streamlit
- Plotly
- Pandas
- NumPy

## 📊 ML Algorithms

- Random Forest
- Feature Engineering
- StandardScaler
- SMOTE

```bash
pip install -r requirements.txt
streamlit run app/app.py
